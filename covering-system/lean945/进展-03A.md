### L2 一般容量引理 —— ✅（`Lean945/Counting.lean` + `Lean945/Capacity.lean`）

计数层（全部用 `Finset.card_bij'` 显式双射证明）：

- `card_filter_modEq`：单个剩余类 mod d 在 [0, d·k) 中恰 k 点（双射 x↦(x/d, r)）。
- `card_avoid_lift`：避让计数从 [0,M) 提升到 [0,N)（M∣N；双射 x↦(x/M, x%M)，
  用 `Nat.mod_mod_of_dvd`）。
- `card_avoid_insert`：CRT 步——加入与 M' 互素的模 d，避让计数乘 (d−1)
  （逆映射用 `Nat.chineseRemainder` + `chineseRemainder_modEq_unique`）。
- `card_avoid_prod`：对 U 归纳，[0,∏U) 中避开每个 e∈U 所选剩余类的点数恰为 ∏(e−1)。

容量引理 `capacity_exclusion`：任意 N>0、池 P（元素皆 ∣N 且 ≥2）、
T⊆P 两两互素、S⊆P、剩余函数 r，若 [0,N) 被 S 中各类覆盖且证书不等式
`∑_{P\T} 1/d < ∏_{T} (1 − 1/d)` (★) 成立，则矛盾。
证明即 Python 证书的计数论证：取 U=S∩T，避让集 A 的基数一方面
= N·∏_{U}(1−1/e) ≥ N·∏_{T}(1−1/d)（因子 ∈[0,1]，用 `Finset.prod_le_prod₀`
与 `Finset.prod_sdiff`），另一方面 ≤ Σ_{S\U} N/d ≤ N·Σ_{P\T} 1/d，与 (★) 冲突。
辅助：`prod_dvd_of_pairwise`（两两互素族之积整除 N）。

### L3 组装 —— ✅（`Lean945/Main.lean`）

给定 ℤ 覆盖系 (n i, a i)：每模整除 lcm∣945 故入池；由 n 单射，
每个模 d 的剩余可典范选取 r(d)（Classical.choose 取原像，用
`Int.natCast_mod`、`Int.toNat_of_nonneg`、`Int.emod_lt_of_pos` 把 ℤ 剩余
搬回 ℕ 剩余），于是 [0,945) 被 univ.image n 的各类覆盖；
代入 `capacity_exclusion` + L1 证书得矛盾。

**注**：奇性假设在本证明中未被使用——945 的容量证书排除的是「模互异且
皆整除 945」的一切覆盖系（比 Erdős #7 在 945 处的陈述更强）；奇性为与
《命题与约束.md》的命题保真而保留在假设中。
