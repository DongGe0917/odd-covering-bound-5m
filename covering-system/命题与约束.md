# 题一 · 命题与约束：Erdős–Selfridge 覆盖系猜想（Erdős #7）

日期：2026-11-27。状态：本体仍 OPEN（erdosproblems.com #7，2026-11-27 复核）。

## 1. 精确数学陈述

**覆盖系（covering system）**：有限个同余类 $a_i \pmod{m_i}$（$i\in\iota$，$\iota$ 有限），
若 $\bigcup_i (a_i + m_i\mathbb{Z}) = \mathbb{Z}$，即每个整数 $z$ 至少满足一个 $z\equiv a_i \pmod{m_i}$，则称其为 $\mathbb{Z}$ 的覆盖系。

**formal-conjectures 口径**：Google DeepMind 的 formal-conjectures 仓库以 `StrictCoveringSystem ℤ`
表示「有限同余类族、模数两两不同、模数 $\ge 2$、覆盖 $\mathbb{Z}$」（该定义的文字说明见
erdosproblemaday 对 Erdős #947 的转述；2026-07 的 lcm>10000 排除论文亦将其结果 transport 到
这一官方口径，并给出周期性桥：覆盖 $\mathbb{Z}$ 当且仅当覆盖 $\mathbb{Z}/N\mathbb{Z}$，其中 $N$ 为模数 lcm）。

**猜想（Erdős–Selfridge，Erdős #7）**：不存在满足以下全部条件的覆盖系：

- $\iota$ 有限，模数函数 $n:\iota\to\mathbb{N}$；
- 互异：$n$ 单射（两两不同）；
- $1 < n_i$ 对一切 $i$；
- 全奇：$\mathrm{Odd}(n_i)$ 对一切 $i$；
- 覆盖：对每个 $z\in\mathbb{Z}$，存在 $i$ 使 $z \equiv a_i \pmod{n_i}$。

即以 Lean 形态写（与 2026-07 论文的定理假设逐项一致）：

```
¬ ∃ (ι : Type) [Fintype ι] (n : ι → ℕ) (a : ι → ℤ),
    (∀ i, 1 < n i) ∧ (∀ i, Odd (n i)) ∧ Function.Injective n ∧
    (∀ z : ℤ, ∃ i, z ≡ a i [ZMOD n i])
```

**反例的精确定义**：一个反例就是满足上式存在命题的一组显式数据
$\{(a_i, m_i)\}_{i=1}^k$：$k$ 有限、$m_i$ 两两不同、全为奇数、均 $>1$，
且 $\bigcup_i (a_i+m_i\mathbb{Z})=\mathbb{Z}$。
反例是有限对象，可由独立验证器按周期 $L=\mathrm{lcm}(m_1,\dots,m_k)$ 枚举
$\{0,\dots,L-1\}$ 机械核验（见 `search.py` 的 `verify`）。
赏金：Erdős 悬赏 \$25 给「不存在」的证明；Selfridge 悬赏 \$2000 给首个显式构造
（据 Filaseta–Ford–Konyagin 2000 的转述，非构造性存在证明不在赏格内）。

经典对照例（模含偶数，说明「互异模覆盖」本身不空）：
$0\bmod 2,\ 0\bmod 3,\ 1\bmod 4,\ 5\bmod 6,\ 7\bmod 12$，周期 12。

## 2. 已知必要条件清单（每条注明出处）

设 $\{(a_i,m_i)\}$ 为假想的奇互异模覆盖系，$N=\mathrm{lcm}(m_1,\dots,m_k)$。

| # | 必要条件 | 出处 |
|---|----------|------|
| C1 | $\sum_i 1/m_i \ge 1$（密度论证：各类密度 $1/m_i$，并集密度为 1） | 民间经典论证；2026-07 论文（Mian & Siddique, arXiv:2607.25628）形式化使用 |
| C2 | $\sigma(N) \ge 2N$，即 $N$ 为丰度数或完全数（由 C1 放大到 $N$ 的全部因子：$\sum_{d\mid N,\,d>1}1/d = \sigma(N)/N - 1 \ge 1$）；特别地奇 $N$ 蕴含 $N \ge 945$（最小奇丰度数），$N<945$ 的奇数无一合格 | 同上（该论文的 abundancy floor：no odd $N<945$ qualifies） |
| C3 | 必有模被 3 整除（先有「必有模被 2 或 3 整除」，奇模排除 2） | Hough & Nielsen 2019；BBMST 2022 给出更简证明（erdosproblems.com #7 讨论串转述） |
| C4 | 模不能全为无平方因子数：必有某个 $m_i$ 被某奇素数平方整除 | Balister, Bollobás, Morris, Sahasrabudhe, Tiba 2022（奇+无平方因子覆盖不存在） |
| C5 | $9 \mid N$ 或 $15 \mid N$ | BBMST 2022（同上讨论串转述） |
| C6 | $N > 10000$（Lean 内核认证：对 $10^4$ 以下全部 23 个奇丰度数逐个给出 CRT 容量证书排除；63 条定理仅依赖 {propext, Classical.choice, Quot.sound}，无 sorry） | Mian & Siddique, 2026-07, arXiv:2607.25628 |
| C7（待核） | $\omega(N) \ge 9$（$N$ 的不同素因子个数至少 9） | erdosproblems.com #7 讨论串 2026 年贴出的三篇未评审论文（7→8→9 递进），**未同行评审，引用时须标待核** |
| C8（待核） | 必有某个模 $m_i$ 含 $\ge 4$ 个不同素因子（$\omega(m_i)\ge4$） | 同上讨论串的第四篇未评审论文，**待核** |

注：C7/C8 若成立，将比 C6 更强地压缩搜索空间（$N$ 至少是 9 个奇素数的乘积量级，
最小 $3\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19\cdot23\cdot29 = 9\,699\,690\,969$，
已远超 $10^4$ 量级——但这两条目前只是论坛宣称，本项目只把它们当搜索排序的启发，
不当作排除结论使用）。

## 3. 合法模池刻画

固定候选 $N$（假想覆盖系的 lcm）。则：

- $N$ 为奇数（奇模的 lcm 为奇），且由 C2/C5/C6：$N$ 丰度（或完全）、$9\mid N$ 或 $15\mid N$、$N>10000$；
- 每个模 $m_i \mid N$（lcm 的定义），故**模池**为
  $$P(N) = \{\, d : d \mid N,\ d > 1 \,\}\quad(\text{$N$ 奇，故池中元自动全奇、全互异可选})；$$
- 所选子集 $S \subseteq P(N)$ 须满足：$\mathrm{lcm}(S) = N$、$\sum_{d\in S} 1/d \ge 1$（C1）、
  $3 \mid d$ 对某个 $d\in S$（C3，实际由 $9\mid N$ 或 $15\mid N$ 及 $\mathrm{lcm}(S)=N$ 近乎自动）、
  $S$ 中至少一元被奇素数平方整除（C4）；
- **密度筛（充分排除）**：若连整个模池都不够密度，即 $\sum_{d\in P(N)} 1/d < 1$，
  则任何 $S\subseteq P(N)$ 都不可能覆盖，$N$ 被排除。此即 C2 的可计算形式，
  `search.py` 的 `density_sum / sieve_pass` 实现（精确有理数 `Fraction` 计算，无浮点）。

搜索的有限化：覆盖 $\mathbb{Z}$ 当且仅当覆盖 $\mathbb{Z}/N\mathbb{Z}$ 的 $N$ 个剩余类
（周期性桥），故对固定 $N$ 这是有限问题，可回溯穷举 + 容量剪枝
（`search.py` 的 `search_cover`），也可日后编码为 SAT 交 z3。

## 4. 本项目的双路打法（与立项书一致）

- **A 路（排除推进）**：沿 C6 的路线把已认证下界往上推：对 $N>10000$ 的奇丰度候选逐个
  跑密度筛（已平凡）+ CRT 容量证书 / 回溯排除，产出可判定证书，目标是新的 lcm 下界。
- **B 路（构造搜索）**：在满足 C1–C5 的模池里用回溯/SAT 搜显式构造；找到即反例，
  交 `verify` 独立核验后即为可发表成果（并触发 \$2000 赏格条件）。
